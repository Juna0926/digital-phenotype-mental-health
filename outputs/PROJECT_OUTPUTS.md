## Current authoritative framing

The current README and Portfolio describe this work as a longitudinal mental-health research progression:

**digital phenotype + repeated EMA → participant-level sequences → LSTM PHQ-9 / GAD-7 prediction → derived-feature contribution analysis → personalized monitoring prototype**.

The later symposium-stage framing is used as the main technical description while preserving the project's origin at the Yongin Severance Hospital Digital Healthcare Hackathon and its **Grand Prize** recognition.
